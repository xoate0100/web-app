# Regular system users

**Who this is for:** loan officers, cashiers, tellers, and other staff who use Mifos X Web App for daily operations (clients, groups, centers, loans, savings, collections, reports).

## What you do in this app

After login you get the application shell (toolbar + sidenav). Common workflows:

| Task | Typical menu |
|------|----------------|
| Search / open a client | **Clients** |
| Groups & centers | **Groups** / **Centers** |
| Loan accounts | Client or loan views under **Clients** / **Accounting** |
| Savings / deposits | Client account tabs |
| Collection sheet | **Collections** (if permitted) |
| Reports | **Reports** |
| Tasks / approvals | **Tasks** (maker-checker inbox) |

Your available actions are controlled by Fineract **permissions**. If a button is missing, contact a manager or system admin — it is usually not a bug.

## Demo vs production

Public demo environments (for example credentials shown in developer docs) are **not** for real member data. Use only the URL and credentials your institution provides.
