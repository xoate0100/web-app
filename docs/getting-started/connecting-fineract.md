# Connecting to Fineract

**Who this is for:** [installers/admins](../personas/installer-admin.md) and [developers](../personas/developers.md).

The SPA prefixes API calls with `environment.serverUrl`:

`{baseApiUrl}{apiProvider}{apiVersion}` → e.g. `https://dev.mifos.io/fineract-provider/api/v1`

## Environment files

| File | When used |
|------|-----------|
| `src/environments/environment.ts` | Development (`ng serve`) |
| `src/environments/environment.prod.ts` | Production build |

Key fields:

| Property | Meaning |
|----------|---------|
| `baseApiUrl` | Fineract host (or value from `localStorage` `mifosXServerURL` when server switch is enabled) |
| `fineractPlatformTenantId` | Tenant id header (`default` on many installs) |
| `apiProvider` | Usually `/fineract-provider/api` |
| `apiVersion` | Usually `/v1` |
| `oauth.enabled` | `true` to use OAuth2 token flow |

`.env.ts` is generated by `npm run env` (package version injection).

## Local Fineract

1. Run Fineract locally (see OS guides in [Installation](./installation.md)).
2. Set `baseApiUrl` to `https://localhost:8443` (or your HTTPS URL).
3. Align `fineractPlatformTenantId` with your tenant.
4. For browser CORS issues during `ng serve`, use [backend proxy](../backend-proxy.md) / `proxy.conf.js`.

## Dev / demo defaults

Out of the box, development often targets `https://dev.mifos.io`. Production build defaults may point at `https://demo.fineract.dev` — **change these for institutional deploy**.

## OAuth2

Set `oauth.enabled: true` in both env files when your Fineract instance requires OAuth. Token endpoint uses `environment.oauth.serverUrl`.

## Runtime server switch

When `allowServerSwitch` is enabled (env flag), the login screen can offer a server selector that stores `mifosXServerURL` in `localStorage`.
