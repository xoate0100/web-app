# I18n

Translations use [`@ngx-translate/core` v18](https://github.com/ngx-translate/core) via `provideTranslateService()` in `src/main.ts`.

**Who this is for:** [developers](./personas/developers.md).

## Adding strings

### Templates

```html
<span translate>This text will be translated.</span>
<button [title]="'Add item' | translate">+</button>
```

### TypeScript

```typescript
title = this.translateService.instant('My page title');
// or async:
this.translateService.get('My page title').subscribe((res: string) => { this.title = res; });
```

`TranslateService.currentLang` is a **signal** in v18 — call `currentLang()` when reading (see `I18nService`).

## Extracting strings

```bash
npm run translations:extract
```

Writes `src/translations/template.json`. Maintain per-locale JSON under `src/translations/` and list languages in `environment*.ts` (`supportedLanguages`).

### Mark for extraction

```typescript
import { extract } from 'app/core/i18n/i18n.service';
return extract('A string to be translated');
```

Embedded JSON (`en-US.json`, `fr-FR.json`) is loaded in `I18nService` via `setTranslation`.
